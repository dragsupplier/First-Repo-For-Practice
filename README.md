# First-Repo-For-Practice 🚀

Welcome! This is my first GitHub repository where I'm learning to code and use Git.

## 📝 About This Project

This repository contains simple Python programs to help beginners learn programming:

- **hello.py** - A simple "Hello World" program that greets you
- **calculator.py** - A basic calculator to perform arithmetic operations

## 🎯 What I'm Learning

- How to create a GitHub repository
- Basic Python programming
- Writing clean, commented code
- Using Git for version control
- Following best practices (like using .gitignore and requirements.txt)

## 🚀 How to Run These Programs

### Prerequisites
You need Python installed on your computer. Check if you have it:
```bash
python --version
# or
python3 --version
```

If you don't have Python, download it from [python.org](https://www.python.org/downloads/)

### Running the Programs

1. **Clone this repository** (download it to your computer):
   ```bash
   git clone https://github.com/dragsupplier/First-Repo-For-Practice.git
   cd First-Repo-For-Practice
   ```

2. **Run the Hello World program**:
   ```bash
   python hello.py
   # or
   python3 hello.py
   ```

3. **Run the Calculator program**:
   ```bash
   python calculator.py
   # or
   python3 calculator.py
   ```
